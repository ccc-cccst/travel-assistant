# 项目范围与当前状态

截至 2026-10-22，已完成的基础是 ChinaTravel 本地复现入口、固定数据准备、模型 API 适配以及小规模探索。

历史探索共尝试14条，保存12份行程，11条通过全部官方检查；其中两条没有景点。45次景点访问中40次恰为90分钟。该样本用于发现问题，不代表全数据集通过率，也不能证明后续改进已有效。

## 后续重点

1. 修复已确认的基础实现问题，保留原始基线作为对照。
2. 建立时间、交通、预算和用户锁定安排的可行性检查。
3. 设计交通负担、绕路、停留时间、每日节奏和偏好匹配的体验诊断。
4. 用诊断指导候选选择与局部修改，展示改动原因和前后差异。
5. 数据采用静态基础库、动态按需查询、缓存和版本记录；接口准确性与更新成本需要验证。
6. 通过原始版、实现修复版、体验优化版及同条件大模型参考组比较效果。

## 当前还没有完成

- 完整的前端、后端业务接口和上线服务。
- 实时高德、天气、评论数据的一体化采集与更新。
- 经过验证的体验综合评分和动态修复方法。

每项新功能先用一条 Issue 描述问题和验收例子，再在独立分支开发。实验结果应附方法、样本、版本、资源预算和失败记录。
