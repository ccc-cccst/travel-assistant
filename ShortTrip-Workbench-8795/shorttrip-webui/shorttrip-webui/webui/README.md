# ShortTrip 行程助手网页

## 新建个性化规划

从「旅游助手」工作区根目录运行一次启动命令。启动脚本检查现有虚拟环境、V20 数据、端口和服务连通性。规划器在启动环境读取 `DEEPSEEK_API_KEY`。没有模型凭据时，可通过地点、人数和日期等表单项提交结构化需求。

```powershell
& './ShortTrip-Fusion-Dev/shorttrip-webui/shorttrip-webui/Start-ShortTrip.ps1'
```

可选参数 `-Open` 会打开浏览器，`-Port` 和 `-PlannerPort` 可指定端口。

打开 [新建规划](http://127.0.0.1:8795/?new=1)。输入原话或点选表单后先核对，再启动搜索。候选通过独立核验后会先显示一份完整可读的行程，最终首推和备选到达时可手动切换。刷新会按 URL 恢复需求、任务、已看的方案和天数。「我的行程」可打开本浏览器最近提交的规划。

## 8791 旧链接与浏览器记录

打开旧链接后点「在统一版继续」，8795 会根据原链接恢复任务、候选和已采用的修改。收藏、最近行程与预订标记可在用过旧版的同一浏览器，从「我的行程 → 迁移旧版浏览器记录 → 从 8791 迁入」预览并确认。预订标记可逐项勾选。草稿和可对应到旧行程的所选对话以可下载的副本保留。「撤销最近一次迁入」可撤销本次新增中未被后续改动的项目。

迁出时旧端口需可访问。若需要恢复原来源，从工作区根目录运行 `& './ShortTrip-Fusion-Dev/shorttrip-webui/shorttrip-webui/Start-ShortTrip.ps1' -Port 8791`，然后回到 8795 打开迁移菜单。

最终方案中，点活动卡上的「换景点」「换饭店」或「换酒店」可搜索并指定新地点，换酒店会更新这段连续住宿。景点与用餐时间也可调整。点某一天的「顺路优化」可尝试调整该日景点顺序，预览接驳时间、步行和费用的变化。路线详情中的「试排此方式」支持步行、打车和地铁。每次修改都先按旅行快照复核，确认采用后生成独立版本，从「行程版本」可以重开已采用版本或回到原方案。候选价格为快照参考，待核实的票价、余房等可在「出发前核对」查看。

「评价方案」按当前候选或已采用版本保存采用意向和改动建议。演示入口、30 条冻结需求及复现命令见 [P045 交付验收](../../../combined%20version_personalized/result/experiments/P045_workbench_acceptance/REPORT.md)。

## 打开个性化规划归档

从「旅游助手」工作区根目录运行。

```powershell
python -B -X utf8 './shorttrip-webui/shorttrip-webui/webui/backend/server.py' --demo-routes --port 8790 --personalized-archive './combined version_personalized/result/experiments/P042_search_budget/paired_release/shanghai_hangzhou/new'
```

打开 [上海到杭州三日游](http://127.0.0.1:8790/?trip=personalized&day=1)，或在「我的行程」选择该归档。首推、两份备选和首份可用各有独立候选 ID。切换方案和日签后，刷新会恢复同一份行程和同一天。左栏显示当前方案对偏好的回应，地点链接会定位到对应时间线和地图标记。

后端从完整候选提取活动时刻、接驳和费用，从独立核验读取比较分项。地点索引读取归档注明的数据版本，默认在工作区的 `ShortTrip/artifacts/data` 下找；其他安装位置使用 `--snapshot-roots`。路线详情并列显示归档时刻与另行查询的当前路线。归档以只读方式展示，当前生成能力见 [融合计划](../docs/个性化规划器与工作台融合计划.md)。

桌面为 AI 助手、行程详情和地图三栏。行程地图使用高德标准与卫星底图，路线详情默认加载高德官方嵌入地图。
旧版本放在 `v1/`。

## 运行

**使用固定行程，并在线查询路线**：

```powershell
python webui/backend/server.py --demo-routes --port 8790
```

在第 1 天「京杭大运河杭州景区 → 新白鹿餐厅」打开路线详情，会直接加载高德嵌入路线。选择步行、驾车或公共交通可切换出行方式。「重新查询」会更新地图和预计耗时。有高德路线数据时，弹窗会显示里程、时长和查询时间。

公共交通使用高德 Web 服务查询公交、地铁及混合换乘方案。嵌入地图和「在高德打开」使用同一公共交通入口。可在高德核对班次。路线接口与行程生成独立。[高德路径规划 2.0](https://lbs.amap.com/api/webservice/guide/api/newroute)

**接后端（推荐）**：`python webui/backend/server.py --five-city ../chinatravel-five-city`，打开 http://127.0.0.1:8000 。规划调用 five-city 的规则规划器，路线调用高德（需要 `AMAP_KEY`）。详见 [`docs/webui-api.md`](../docs/webui-api.md)。

**只看页面（示例数据）**：

```bash
python webui/make_sample.py                     # 生成杭州示例（可选）
python webui/export_plan.py                     # 行程 JSON → data/trips.js（加坐标，并导出地图筛选用的城市 POI）
python3 -m http.server 8790 --directory webui   # 浏览器打开 http://localhost:8790
```

导出自己的规划结果：`python webui/export_plan.py --plan results/xxx.json --query q.json --title "重庆2日游"`。
多个 `--plan` 用同一个 `--title` 时，会被当成同一段对话的多个版本。

网址参数：

- `?api=http://127.0.0.1:8000`：连接后端（接口见 [`docs/webui-api.md`](../docs/webui-api.md)）
- `?llm=http://127.0.0.1:18080&model=…`：mock 模式下左栏对话直连 llama-server
- `?trip=<id>&day=2`：直接打开某个行程的第 2 天

## 文件

| 文件 | 作用 |
| --- | --- |
| `api.js` | **唯一的数据适配层（坑位）**。mock 和 http 两种模式，ChinaTravel plan 到视图模型的转换也在这里 |
| `app.js` | 页面逻辑：状态、渲染、三栏联动、编辑操作、地图 |
| `index.html` / `style.css` | 结构和样式 |
| `export_plan.py` | 给行程 JSON 补坐标，写出 `data/trips.js`（`window.TRIPS` 和 `window.POIS`） |

## 功能

本地预览在 `http://127.0.0.1:8790/`。工作台会按行程里的起终点和出行方式查询所选日期的路线。高德返回沿线坐标后，主地图会逐段画出实线。步行和驾车也可使用 OpenStreetMap 道路参考。查不到沿线坐标的路段标为待核实，可在地图上重试。地图更新保留规划器核验的日程、时长和费用。点击路线或时间线可查看详情，也可在高德打开。`data/road-reference.js` 含两个杭州方案的 19 条道路参考。 [OpenStreetMap 数据归属](https://www.openstreetmap.org/copyright) · [高德嵌入路线](https://lbs.amap.com/api/uri-api/guide/embedded-map/embedded-route)

「出发前核对」列出时间冲突、已知道路接驳缺口和待核实的路段。「比较版本」可比较包内两份杭州行程的费用、道路接驳、步行和景点停留。顺序调整造成新增的时间重叠时保留原行程，可以通过地点菜单改时刻。分享可以导出当前地点和时刻的 JSON 文件。示例新建先确认原话，再打开固定样例。桌面仍使用对话、行程、地图三栏，手机从「地图」切换视图。

- **顶栏**：☰ 我的行程（抽屉，可以新建）、点标题直接改名、设置出发日期（日期显示在每天的标签上）、满意度调研、历史版本、下载（页面 JSON / ChinaTravel JSON / 打印）、分享当前行程文件
- **左栏 AI 助手**：用户气泡；「深度思考已完成」可展开；导览卡片用 markdown 渲染，地名可点击，在行程里的地名后面带 ✓；↓ 回到底部；输入框按 Enter 发送。说「调整 / 换成 / 删掉…」会走异步重新规划，显示进度卡片，完成后可以保留新版本或回到上一个版本。收起后左下角有浮动按钮
- **中栏**：行程详情、旅行灵感、预订管理三个 tab；图文 / 列表两种视图；展开（隐藏地图）；标签行有总览、第 N 天、待安排、备注和 ＋ 加一天，滚动时标签和地图会跟着切到对应的天
  - 总览：每天一张卡片（A → B → 住在 X），另有待安排、备注
  - 每天：标题（可改）、添加备注、顺路优化、时间线卡片（图片、建议游玩时长、开放时间、价格、时间段）、两项之间的交通（可以展开看分段）
  - 卡片「…」：备注、移动到、上移、下移、复制到、删除；悬停时左侧出现多选框（批量移动 / 复制 / 删除），右侧有拖动排序、↻ 替换（附近候选）、✦ 问 AI
  - 天的「…」：改标题、插入一天、清空到待安排、删除这一天
- **右栏地图**：筛选按钮（景点带评分下拉、酒店、美食、购物、机场、火车站、收藏，可以横向滚动）
  - 推荐地点用绿点显示；离得近的合并成「N / XX等」气泡，点开是「景点N个」列表（带 🔥 热度）；单个地点可以加入当天或待安排，也可以收藏
  - 行程点：蓝色编号标点加地名。总览按天着色并标「第N天」；看某一天时其他天变淡，并显示每段的用时标签（🚶 16分钟）
  - 右下角：查看全部、图层（标准 / 卫星 / OSM）、定位、放大、缩小；比例尺
- 中栏、地图、左栏地名三者联动：点哪一个，另外两个都会定位并高亮

## 待接入的数据

都在 `docs/webui-api.md` 里标了【坑】：

- 地点图片 `image`、评分 `rating`、热度 `heat`：数据库里目前没有
- 沿道路的路线：后端已接高德 v5 路径规划，配置 `AMAP_KEY` 后生效
- 规划、修改：后端已接 five-city 规则规划器（只识别城市/天数/人数）；对话需要启动 llama-server
- 旅行灵感、预订链接：目前是示例内容
