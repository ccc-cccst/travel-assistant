# 软约束翻译实验记录

更新日期为2026-11-16。基础模型Qwen/Qwen3.5-4B固定于版本851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a，冻结BF16参数，以rank 8、alpha 16、dropout 0.05训练LoRA。

## 数据与评测条件

用户提供300条样本，简单、稍模糊、非常模糊各100条，固定划分240／30／30。原始数据SHA256为743fc1302a0a2f97e4dd7bfbd623f057b116456de96664ecbfcb7060abda0101。第二轮的30条评测数据已参与第一轮错误分析，本报告按回归实验记录。标注继承原数据，语义仍需人工审查。

服务器三组统一使用第二轮提示词、贪心解码、关闭思考。Q8在本地llama.cpp Vulkan运行，服务器BF16采用PyTorch参考注意力实现。两者硬件、推理后端及合并精度存在差异，量化效果需在统一条件下另行比较。

## 第二轮调整

- 明确JSON字段类型、当前出行意图、目的地菜系绑定、否定、撤销、条件与组合逻辑，完整示例取自训练集。
- 答案监督中DSL值权重为3，未映射字段值为2，其余答案token为1，提示词为0。
- 最大长度由1024调整为2048。运行前检查实际长度，禁止截断答案。
- 每30步生成验证集答案，按DSL整条匹配选择最佳检查点，第60步被选中。
- 每10步保存完整状态与校验，保留最近及最佳检查点，训练进程最多恢复两次。
