# Qwen3.5-4B BF16 LoRA软约束翻译实验

数据使用用户于2026-11-15提供的dataset.json，原文件完整保存于data目录。三个难度各100条，固定划分240条训练、30条验证、30条测试。分组依据和编号在data/split_manifest.json中。标签语义准确性尚未经独立人工复核。

训练使用Qwen/Qwen3.5-4B官方权重，版本记录于model_manifest.json。基础语言模型冻结并保持BF16，语言层线性模块使用rank 8、alpha 16的LoRA。只监督JSON答案，最大长度1024，不截断输入或答案。batch size为1，梯度累积8，学习率0.0001，最多5轮。每10步计算验证损失并保存完整检查点，以验证损失选择最佳适配器，连续6次验证未改善提前结束。

先执行5步训练验证，再从原始基础权重开始完整训练。每个训练进程独立运行。现有training_protection.py负责完整检查点发布与完整性验证，保留最近两个及最佳检查点，支持优化器、调度器和随机状态恢复。

数值检查发现当前FLA 0.4.0加速路径在该服务器输出NaN。同一条数据使用PyTorch参考实现时，损失为0.23786，全部LoRA梯度均为有限值。因此训练与评测统一使用PyTorch参考线性注意力实现，基础权重保持BF16。发布包保留check_numerics.py用于复查数值。

训练完成后，在同一BF16模型上分别关闭和启用LoRA，对测试集生成输出并保留逐条结果。evaluation/comparison.html展示全部输入、标准答案和两组输出。自动指标包括JSON格式、DSL匹配、约束精确率和召回率、证据完整性。未映射要求的语义仍需人工复核。

环境配置、训练顺序和可复用命令见[训练入口](../README.md)。所有路径相对于当前实验目录，运行状态位于experiment_status.json。
