# 第二轮BF16 LoRA软约束翻译实验

使用用户提供的300条数据和上一轮固定划分，训练240条、验证30条、回归30条。原有标注保持原样。上轮30条测试数据已用于错误分析，本轮按回归评测记录。

新版提示词明确三个字段的完整JSON类型，补充当前意图、目的地绑定、项目已有城市菜系映射，以及否定、撤销、条件和组合逻辑规则。完整JSON示例取自训练集第一条，提示中不加入验证或回归样本。

训练仍使用原始Qwen3.5-4B权重，冻结BF16基础参数。LoRA rank 8、alpha 16、dropout 0.05，学习率0.0001，batch size 1，梯度累积8，最多5轮。DSL值token的损失权重为3，未映射字段值为2，其他答案token为1，提示词token为0。最大长度2048，实际长度在训练前检查，禁止截断答案。

每10步保存完整检查点，每30步在验证集上实际生成答案。最佳适配器依据验证集DSL整条匹配率选择，连续3次验证无提升提前结束。检查点包括优化器、调度器、随机状态与完整性校验，异常退出最多恢复2次。

使用数值检查通过的PyTorch参考线性注意力实现。两轮采用同一固定版本基础权重，分别保存缓存、输出与检查点。

训练后对原始4B、第一轮LoRA、第二轮LoRA使用相同新版提示词进行回归评测。JSON语法、接口结构、DSL词表合法性、DSL整条匹配及未映射覆盖分别统计。输出在evaluation/comparison.html，逐条展开。

环境配置、训练顺序和可复用命令见[训练入口](../README.md)。所有路径相对于当前实验目录，运行状态位于experiment_status.json。
