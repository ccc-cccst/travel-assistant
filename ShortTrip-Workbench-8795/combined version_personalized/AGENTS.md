# 实验记录

项目的主要实验统一记录在 EXPERIMENT_LOG.md。

- 开始主要实验时，追加编号、假设、对照、控制变量、预算、复现命令及输出目录。
- 实际运行后补充关键结果、发现的问题、解决方案、实施状态和复测证据。
- 区分设计、单元测试、真实运行和待验证结论；保留失败、异常和不支持假设的结果。
- 已有实验结果不覆盖；配置或代码变化后的复测使用新的运行目录或标签。
- 新实验的结果和报告写入 result/experiments/，单条规划默认写入 result/manual/。
- 现有 artifacts/ 中的运行、快照和报告沿用原路径。记录文件保留可追溯链接。

# 错误与经验

- 修复已发现问题时同步维护LESSONS.md：现象、原因、修复、适用范围、复测证据与状态；保留未知原因。
- 可自动规避的经验通过lessons/rules.json配置已注册handler，必须经过验证并保留回归。不把一次超时或缺数据写成永久路线黑名单。
- 规划失败保存统一ERROR.json及result/incidents发生记录，区分金额预算、搜索时限、模型限流、数据缺失、约束冲突与运行异常。
